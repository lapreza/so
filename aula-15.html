Gerenciamento de Pacotes, Discos, Partições e Montagem de Unidades

Estudo sobre a administração de armazenamento secundário em Linux, tabelas de partição (MBR e GPT), formatação de sistemas de arquivos, gerenciamento de pacotes (apt) e comandos de disco (fdisk, mkfs, mount).

1. Gerenciamento de Pacotes e Repositórios

Diferente do modelo tradicional de instalação por executáveis isolados, os sistemas operacionais modernos utilizam Gerenciadores de Pacotes. O gerenciador resolve dependências de software automaticamente, realiza a checagem de assinaturas de segurança e baixa arquivos diretamente de repositórios oficiais.

Em distribuições baseadas em Debian e Ubuntu, o padrão da indústria é a ferramenta APT (Advanced Package Tool):

# Atualiza o índice local de pacotes disponíveis

sudo apt update

# Atualiza todos os softwares instalados no sistema

sudo apt upgrade

# Instala um pacote resolvendo dependências automaticamente

sudo apt install nginx htop net-tools

2. Organização Física e Lógica de Armazenamento

Para que o Sistema Operacional possa armazenar dados num disco rígido (HDD) ou unidade de estado sólido (SSD/NVMe), a unidade física deve passar por três etapas lógicas indispensáveis:

1. Particionamento: Divisão do disco em seções lógicas independentes usando padrões de tabela como MBR (Master Boot Record) ou o moderno GPT (GUID Partition Table).
2. Formatação (Criação de Sistema de Arquivos): Gravação da estrutura de diretórios e tabelas de alocação de blocos na partição (ex: ext4, xfs, ntfs, btrfs).
3. Montagem (Mounting): Associação da partição formatada a um diretório na árvore do sistema de arquivos único (/).

3. Roteiro Prático no Terminal: fdisk, mkfs e mount

Etapa A: Identificação e Particionamento (fdisk / lsblk)

# Lista todos os discos e partições conectadas ao sistema

lsblk

# Inicia o utilitário interativo de particionamento no disco /dev/sdb

sudo fdisk /dev/sdb

Etapa B: Formatação com Sistema de Arquivos ext4 (mkfs)

# Cria o sistema de arquivos ext4 na partição recém-criada /dev/sdb1

sudo mkfs.ext4 /dev/sdb1

Etapa C: Montagem e Montagem Persistente (mount e /etc/fstab)

# Cria o ponto de montagem e conecta a partição

sudo mkdir -p /mnt/dados

sudo mount /dev/sdb1 /mnt/dados

4. Montagem Automática no Boot (/etc/fstab)

O comando mount realiza apenas uma montagem temporária na memória RAM. Ao reiniciar o sistema, a partição é desmontada.

Para tornar a montagem permanente, a partição e seu respectivo UUID (Identificador Único Universal obtido com o comando blkid) devem ser cadastrados no arquivo de configuração /etc/fstab do Linux.

5. Questões para Fixação e Discussão

Questão 1:

Diferencie a tabela de partição clássica MBR da tabela moderna GPT. Quais são as limitações principais de tamanho de disco e número de partições primárias do MBR?

Questão 2:

Explique a importância do arquivo /etc/fstab e descreva o risco de incluir uma linha com sintaxe incorreta nesse arquivo antes de reiniciar o sistema.
